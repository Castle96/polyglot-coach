# Local LLM Models

The current default local language model for Polyglot Coach is Qwen2.5 7B.
Both Ollama and GGUF (llama-cpp-python) backends are supported.

## Download

Download compatible GGUF weights from Hugging Face and place them in this directory.
Large model files such as `.gguf` assets are ignored by git.
